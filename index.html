Connection checklist

      

        
Register the exact redirect URI
Scheme, host, path, trailing slash, and environment must match exactly. OAuth providers are petty about this, as tradition demands.

        
Use authorization code + PKCE for public clients
Browser, desktop, mobile, and CLI apps should not ship client secrets.

        
Never paste client secrets into this page
This is static and client-side. It intentionally generates placeholders for secrets.

        
Request the smallest usable scope set
Start narrow. Add scopes when the feature truly needs them. Your future security review will mutter less.

        
Store tokens server-side when possible
Encrypt refresh tokens. Rotate, revoke, and log consent changes.

        
Keep dev, staging, and prod apps separate
Separate client IDs make debugging and incident response dramatically less cursed.
